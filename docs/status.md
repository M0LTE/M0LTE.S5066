- 2026-11-07: P3-7 (issue #26): the T3 simulation harness in `tests/M0LTE.S5066.Core.Tests/T3/`. Real nodes over a seeded channel model: per-receiver block errors, missed bursts and mid-burst fades, half duplex, one burst at a time per receiver (an overlapping burst corrupts the one being received), and configurable host latency, receive-to-transmit turnaround and end-of-burst reporting delay. Everything is drawn from one seed and events run in a total order, so a run is reproducible exactly. The simulation checks C-0844 and C-0889 itself: no node starts a burst before the end announced by an EOT its core had been given; a rogue-node test shows the check fails when it should. It also checks every announced EOT is no earlier than the true end (C-0891). Tests: broadcast from one node to two receivers with loss while the receivers also broadcast (five seeds), long bursts with fades so that only VDCD keeps a receiver quiet (review: without fades the broadcast test passes even with VDCD disabled; this one fails then), loss-free delivery with every repeat sent (A-0081), determinism, and the reception window commitment under latency (C-1052). Finding on C-1052: with jitter or ed3 contention, or slotted below the last position, no repeat is dropped at 0 to 300 ms of latency, because the window allows `num_cont_slots` whole slots per later transmission and those modes never wait that long after their own transmission (K-0080, K-0082), so at least one slot (3 s by default) is spare. Slotted at the last position waits all of them (K-0082), so the only slack is the transmission time not usable as whole blocks plus the window's half-second rounding, which can both be zero: in the test, any latency at all drops the last repeat of every U_PDU (30 of 40 copies sent), and at 50% block loss the deliveries fall from 79 to 74 of 80. Earlier repeats are never dropped, since a window stamped while two or more transmissions are owed covers a whole extra allowance. Protocol behaviour unchanged; the fix, if wanted (for example a latency allowance in X of C-1051), is a later decision. Also found: issue #35 (address size and broadcast). Phase 3 complete.
